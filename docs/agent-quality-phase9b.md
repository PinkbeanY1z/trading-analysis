# 9B：问题优先研究与独立方案评估

更新：2026-11-01。分模块交付；本记录将随实际验证更新，不将离线测试替代真实模型与回答质量验收。

## 起点审计

`tools.py` 中 `calculate_technical_indicators` 与 `analyze_market_structure` 原本逐字执行相同的 `compact(await snapshot(...))`。前者并未返回指标专项投影，后者也未提供独立的方案评估。`get_market_data`只是在相同快照上增加K线，`compare_timeframes`则遍历相同结果。

同一轮的RUN缓存已避免相同品种/周期重复调用MarketService.get，因此问题主要是重复的工具返回与模型上下文，而非每次工具都重新请求供应商。MarketService本身缓存原始K线，随后图表GET仍会重新计算指标，这也是待优化点。

`report.sections`每周期固定追加趋势、指标、RSI、量价、支撑阻力、风险六段，再追加多周期、结论依据与模型解释。三个周期加两段解释即22项；生成循环不读取用户问题。原协议只有方向枚举和少量解释，不具备子问题覆盖或独立风险收益结果。

## 模块1：确定性风险收益服务（已实现）

新增 `POST /api/analysis/risk-reward`，明确的多头/空头入场、止损、目标价格输入，支持可选手续费、点差和滑点（均为报价货币、每单位、往返固定成本）。缺失成本保持null/未确认，不冒充已完整计入。ATR只用于距离提示，不选择止损，不据此确认方案有效。

内部Decimal运算，不提前四舍五入；计算完才转换JSON数值。毛风险/收益、多空方向、净风险/收益/盈亏比、理论盈亏平衡所需胜率均由Python计算。实际历史胜率始终null、unverified。

690入场、680止损、720目标的假设多头：毛风险10、目标收益30、盈亏比3；理论盈亏平衡门槛25%，不等于实际胜率。未提供交易成本时明确提示测算不含未知成本，也不宣称这些是假设当下可成交报价。

实际验证：原148项Python测试加41项计算服务与3项API测试，共192项通过；前端原19项及构建通过。数字合法性/顺序/多空/成本/非正净收益/ATR/精度/假胜率防护均覆盖。CI与具体Commit以本模块交付关联记录为准。
